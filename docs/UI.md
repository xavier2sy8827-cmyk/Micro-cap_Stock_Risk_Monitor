# UI 规范（一期）

## 总则

1. **监控优先**：页面只回答"现在什么状态、和历史上比如何、有没有触发阈值"，不做选股/持仓/收益排名。
2. **能图则图**：优先用热力图/线图/带状图表达；表格只用于事件、分层收益这类天然表格的数据。
3. **默认折叠**：每个图卡默认收起，卡头显示"标题 + 最新值 + 分位 + asof"，点开才渲染图表（懒加载）。
4. **范围可设**：每张图内提供 `4W / 12W / 26W / 52W / 1Y / 2Y / 5Y / 全部`，**默认 4W**；选择记入 localStorage（`wp-range-v2`）。
5. **移动优先**：360px 不横滑；图表高度 220–280px；触控目标 ≥44px；safe-area。
6. **数据诚实**：每个区块标注 asof（`data_through` / `margin_through` / `factor_ic_through` / `industry_version`）；滞后、降级、缺失用黄条，不隐藏。

## 图卡结构

```
┌──────────────────────────────────────────────┐
│ 标题                       最新值 · 分位 · 态 │  ← 收起时可见
│ 副标题（口径/窗口/asof）              [展开 ▾] │
├──────────────────────────────────────────────┤
│ [4W][12W][26W][52W][1Y][2Y][5Y][全部]         │  ← 展开后
│                                              │
│                 图表区                        │
│                                              │
│ 口径脚注（可折叠）                             │
└──────────────────────────────────────────────┘
```

- 收起状态不初始化 ECharts；展开时按当前范围取数并渲染。
- 图卡之间用 1px 分隔线，不做重阴影卡片堆叠。
- 阈值线：预警/高危用固定颜色 + 标签；分位面板 80/85/90 线常显。
- 涨跌色：A 股习惯，红涨蓝跌；正/负分位不套用涨跌色。

## 移动端细节

- 底栏 5 tab：总览 / 拥挤度 / 全A / 内部 / 更多；因子、两融、关于从「更多」进入。
- 页内用吸顶 section chips 快速跳转。
- 图卡收起时整行可点，展开箭头在右；展开后图表全宽。
- 深色模式跟随系统，可手动切换并记忆。
- 数字用 tabular-nums；百分比保留 2 位，分位取整。
