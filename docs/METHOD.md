# 口径与方法（一期）

所有数据来自 Tushare，代码位置 `pipeline/wp/`。常量集中在 `config.py`，改口径先改常量再同步本文。

## 1. 股票池

| 池 | 定义 | 用途 |
| --- | --- | --- |
| `pool_total400` | 总市值最小的 400 只 | 宽度、拥挤度、qs、10 层、5 因子 |
| `pool_circ1000` | 流通市值最小的 1000 只 | **仅**两融主指标；`wp400` 两融为观察列 |

- 选股使用 **T-1** 的 `daily_basic`（避免用当日收盘后的信息选当日池）。
- 剔除：北交所（`.BJ`）、科创板（`688/689`）、B 股（`900/200`）。
- 上市不足 60 个自然日、T-1 为 ST、T-1 处于退市整理期（`namechange.change_reason` 含“退市整理”或名称以“退”结尾）的股票剔除。
- ST 用 `stock_st` 的 T-1 快照（点位正确）；`stock_basic.name` 只做诊断，不参与历史过滤。
- 停牌股：`daily_basic` 当日无行时，按个股向前回看至多 300 个自然日取最近一次估值（总/流通市值、PB、换手），回看窗口 400 自然日。

## 2. 行情与复权

- 日线：`daily`（open/high/low/close/pre_close/amount）。
- 复权：用 `close/pre_close` 连乘得到前复权链（`qfq_chain`），不引入 `adj_factor`；停牌日按最近收盘价 ffill。
- 收益：`close/pre_close - 1`；等权收益 = 池内成分等权平均。

## 3. 指标

| 指标 | 定义 |
| --- | --- |
| `breadth10` | 池内收盘价 > MA20（含当日）的股票占比 ×100 |
| `wp400_index` | 池内等权日收益累乘指数（基点 1） |
| `ratio_top5/10` | 全市场（剔北交所）成交额前 5%/10% 股票成交额占比 ×100 |
| `all_money` | 全市场成交额合计（亿元，`amount/1e5`） |
| `money_300/500/1000/2000` | 对应指数成交额（亿元） |
| `money_wp400` | 池内成交额合计（亿元） |
| `share_*` | 各层成交额 / `all_money` ×100 |
| `ret_ma5_*` | 各层等权日收益 5 日均值 ×100（%） |
| `pb_spread` | 全市场（剔北交所）按总市值最小 20% 与最大 20% 分组，组内 PB>0 的中位数之比（小/大） |
| `corr60_wp400` | 池内成分最近 60 个交易日收益的截面平均相关（至少 30 只） |
| `ls_vol_ratio` | 池内等权收益 20 日波动 / 全市场等权收益 20 日波动 |
| `qs_share` | 池内“成交额分位 <40% 且换手率分位 >60%”股票的成交额占池内成交额比例 ×100 |
| `qs_share_abs` | 绝对口径：成交额 <4000 万且换手率 >3% 的成交额占比 |
| `breadth_L1..L10` | 按总市值升序把池切成 10 层（每层 40 只），层内宽度（MA20 用 T-1） |
| `s_width` | 行业宽度四舍五入后求和（28/31 个行业随版本切换） |
| `n_industries` | 当日有有效宽度的行业数；`s_width_pct = s_width/n_industries` |
| `margin_pool_ratio` | circ-1000 池融资余额 / 全市场融资余额 ×100 |
| `margin_pool_buy_ratio` | circ-1000 池融资买入额 / 全市场融资买入额 ×100 |
| `margin_wp400_ratio` | 总市值 400 池融资余额 / 全市场融资余额 ×100 |
| `margin_pool_ratio_z` | 上述比值的 90 日滚动 z-score（至少 30 个观测） |

### 分位

- 短周期分位：250 日滚动分位（至少 120 个有效值）。
- 长周期分位：750 日滚动分位（至少 250 个有效值）；`_pct_exp` 为扩展窗口分位（至少 250 个）。
- `s_width_pct` 不是分位，是当日宽度均值。

### 行业

- SW2014（28 个一级行业）用于 `< 2021-12-13`，SW2021（31 个）用于 `>=` 该日。
- `index_member` 按 `in_date/out_date` 重建每日成分；同一股票同版本取最后一条。
- 行业宽度只统计当日有行情的成分；`n_valid` 一并落 CSV。

## 4. 五因子

因子在 `pool_total400` 上计算，面板为 `date × ts_code`。

| 因子 | 方向 | 定义 |
| --- | --- | --- |
| `F1_SIZE` | 小市值 | `-ln(circ_mv)` |
| `F2_DIV` | 高股息 | `dv_ttm`，缺失填 0 |
| `F3_AMPL` | 低振幅 | `-(high-low)/pre_close` |
| `F4_INTRA_REV` | 日内反转 | `-(close/open-1)` |
| `F5_RESID_REV` | 残差反转 | 对 `ret20` 回归 `S/|S|`（S 为 20 日小额净流入），取 `-ε_T`；拟合窗 `[T-20,T-1]`，S/ret 窗口含 T |

- 前视收益：`fwd1/fwd5/fwd20 = qfq.shift(-k)/qfq-1`，最后 20 个交易日无 `fwd20`，因子页尾部留空。
- Rank IC：每个交易日对 `factor` 与 `fwd20` 做 Spearman 秩相关（样本 ≥30，因子值不全相同）。
- 多空：按因子值分 5 组（`qcut`，样本 ≥25 且 ≥5 个不同值），`ls_ret = Q5 - Q1` 的 `fwd1` 均值；`ls_nav` 为 `ls_ret` 累加。
- IC 均值/IR：`ic_mean_252`、`ic_mean_756`、`icir_252 = mean252/std252`（`ddof=0`）。

### 四态

| 状态 | 条件 | 页面 |
| --- | --- | --- |
| L（失效） | `ic_mean_252` 的扩展分位 <30% **或** `icir_252 < 0.5` | 黄色 |
| D（衰减） | 756 日均值绝对值 <0.02 或符号翻转，或 `mean252/mean756 < 0.5` | 黄色 |
| R（回撤） | `ls_nav` 回撤 ≤ 历史最差回撤（T-1 前）或回撤 >2σ（252 日），且 10 个交易日内二次触发确认；持续到 NAV 回到事件前高点 | 红色 |
| F（转负） | 最近 3 个**已完结**自然月的月均 IC 均为负 | 红色 |

- 状态优先级：R > F > (L 或 D) > 正常；`judge_nan=1` 表示四态条件尚未成熟（数据不足 252/756 日等），前端不做“正常”解读。
- 事件表 `factor_events.csv` 记录 R 的首次触发、确认日、结束日、深度与 σ 倍数。

## 5. 两融

## 7. 校验

- `python -m wp manifest`：对每个输出 CSV 生成 sha256、行数、列数、日期范围与代码 commit。
- `python -m wp verify`：检查行数、日期覆盖、关键列非空率、因子面板尾部 20 日为空等不变量。
- `pytest`：池规则、CSV 读写、字段断言、因子尾部掩码等 28 个用例。
